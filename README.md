# Python Expense Tracker

A simple command-line expense tracker built with Python.

The application allows users to add expenses, store them in a CSV file, view expense history, and calculate total spending.

## Features

- Add expenses
- Store expenses in CSV
- Automatic date for each expense
- Input validation
- View saved expenses
- Calculate total spending
- Simple interactive menu

## Technologies

- Python
- CSV
- Git
- GitHub

## How to Run

Clone the repository:

```bash
git clone https://github.com/adalyatixten/python-expense-tracker.git
```

Open the project folder:

```bash
cd python-expense-tracker
```

Run the program:

```bash
py main.py
```
